Design a system to simulate a secure and transparent digital voting process for
environments such as student councils, clubs, or even food or animal. This system
supports role-based access for three main user types: Admin, Voter, and Candidate.
Each role has specific functions:
 Admin manages the entire election process, including registering candidates
and voters, starting and closing the election, and viewing final results
including history result.
 Voters register and log in, view candidate details, and cast a vote. Each voter
is allowed to vote only once.
 Candidates can log in to view and update their campaign details.
 If candidates is not a person, the admin will access to update the details
Objective and Scope
The goal of this system is to provide a simple, secure, and fair digital voting
experience. It is designed for use in environments like student elections or club voting,
where transparency and one-person-one-vote enforcement are important.
